# Quiz Game

A simple, interactive quiz game built with HTML, CSS, and JavaScript. Test your knowledge with 5 multiple-choice questions on general topics.

## Features

- **Start Screen**: Welcome message and start button to begin the quiz.
- **Quiz Interface**: Displays questions one at a time with 4 answer options.
- **Progress Tracking**: Visual progress bar and question counter.
- **Score Calculation**: Tracks correct answers in real-time.
- **Results Screen**: Shows final score and personalized feedback message based on performance.
- **Restart Option**: Ability to restart the quiz after completion.
- **Responsive Design**: Works on desktop and mobile devices.

## How to Run

1. Clone or download the project files.
2. Open `Starter/index.html` in any modern web browser.
3. Click "Start Quiz" to begin.
4. Answer the questions by clicking on the options.
5. View your results and restart if desired.

## Technologies Used

- **HTML**: Structure and content.
- **CSS**: Styling and responsive design.
- **JavaScript**: Game logic, question handling, and interactivity.
